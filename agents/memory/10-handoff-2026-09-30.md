## Traps this session paid for, so you do not

- **A full battery costs 4.19 GB, not 33 GB**, with `CARGO_PROFILE_DEV_DEBUG=0` and
  `CARGO_PROFILE_TEST_DEBUG=0` (measured, M208; the rule is in `AGENTS.md`). Disclose the knob in the
  commit, and turn debug info back on for a round that debugs a failure.
- **Bulk string surgery costs a round trip every time.** Three incidents: a `-replace` with an empty
  match collapsed a whole file to one line; a `Set-Content` missing `-Value` silently did nothing; and
  a PowerShell **literal here-string** (`@'…'@`) does not unescape `''`. **Grep for the string you
  expected to appear** before believing an edit landed.
- **`scripts/console-probe.py`:** `--settle` is honoured only on the `--during`/`--enter` turn branch —
  a `--submit` run's JSON has no `turn_screen` key. Use **`--at SECONDS`** to wait before the capture,
  and route an argument list through a one-line `.cmd` wrapper because `--submit` quoting mangles it.
- **One build owner at a time**, `CARGO_BUILD_JOBS=1`, target dir outside the repo: a build inside
  this directory fails with `D8050 cannot execute c1.dll`.
- **A claim about a user's screen is verified by looking at it.** The two most valuable findings this
  session (A19, A20) came from measuring the installed binary, not from reading code — and A19 was
  only found because a *failed* measurement was treated as evidence instead of a probe limitation.

## The method that produced most of the value here (14 rounds of it)

**Read the code behind a sentence before believing the sentence — and when a check fires, verify the
convention it assumes.** Eleven claims were checked that way this session; **six were wrong and two of
those would have cost real time** (a build failure from dropping a dependency still in use; a slice
twice the size it appeared to be). Three checks *confirmed* rather than corrected, and in all three
**the check's own premise was the thing that was wrong** — a consistency script that would have added
121 unmaintained rows, a "missing from --help" alarm that turned out to be a stated scope, and a
"redundant code" claim that needed a line number before it was evidence.

The cheap form of this review is one read and no build. Every one of the eleven cost that much.

Three specific habits, all of which paid:

- **After changing a shape, grep for what assumed the old one.** Four stale claims (A7, A10, A11, A20)
  came from exactly that, and the M205→M210 case shows it can be your *own* recent work.
- **When a fix removes code, ask what message it orphaned.** A19's fix would have silently dropped the
  resume-specific refusal; the open's error mapping now selects between two messages instead.
- **A user-facing document is wrong by definition when what the user sees changes.** Two rows
  (`sessions.md`, `troubleshooting.md`) described a refusal where the user now watches a countdown.
