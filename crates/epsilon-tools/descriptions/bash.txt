Execute one shell command in the workspace root (PowerShell on Windows, bash elsewhere), or in `workdir` when given — a workspace-relative subdirectory, resolved and escape-checked like any path, so never `cd &&` into one. Returns combined stdout/stderr, exit code, and duration. Output beyond 2000 lines / 64KB is truncated; the full output is saved and its path is included so you can read it. Timeout defaults to 120s (max 600).
