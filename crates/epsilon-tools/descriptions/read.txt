Read a text file with line numbers. Returns up to 2000 lines / 256KB per page; pass offset (1-based) and limit to page through larger files. Every page that stops early ends with the offset that continues it — keep reading with offset until the file ends. An offset past the end of the file is an error; a single line longer than 256KB is reported with a bash/sed fallback instead of content. Refuses binary files. Paths must stay inside the workspace.
